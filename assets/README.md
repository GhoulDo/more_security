# Assets para More Security

Este directorio contiene todos los recursos visuales y de diseño para la aplicación More Security.

## Estructura de directorios

- `images/`: Imágenes generales y fondos para la aplicación
- `icons/`: Iconos utilizados en diferentes partes de la aplicación
- `animations/`: Animaciones Lottie para experiencia de usuario mejorada
- `fonts/`: Archivos de fuentes (Poppins)

## Requisitos para assets

### Imágenes

- Formato: PNG o JPG
- Resolución: Mínimo 2x (alta densidad)
- Tamaño: Optimizadas para móviles

### Iconos

- Formato: PNG
- Resolución: Múltiples densidades (1x, 2x, 3x)
- Preferiblemente con fondo transparente

### Animaciones

- Formato: JSON (Lottie)
- Tamaño: Optimizadas para rendimiento móvil
- Duración: preferiblemente menor a 3 segundos

### Fuentes

- Formato: TTF
- Pesos requeridos: Regular, Medium, SemiBold, Bold
